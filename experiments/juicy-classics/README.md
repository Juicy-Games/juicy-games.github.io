# Juicy Classics

Juicy Classics is a playable experiment in game feel, inspired by the Juicy Breakout demo. It reworks seven arcade games and prototypes: Flappy, Tetris, Pong, Dino, Breakout, Snake, and Angry.

[Play Juicy Classics](https://juicy-games.github.io/experiments/juicy-classics/)

Use the **Juice Lab** to compare presets or tune individual effects such as sound, particles, screen shake, and freeze frames. The **Potentiality** controls let you explore how players build up and release energy through play. In Snake, for example, collecting sparks builds a charge that can break through a wall.

The companion **Juicy Game Design** repository contains the design guide for researchers and coding agents such as Codex and Claude Code. It describes the feedback and potentiality patterns explored in these games.

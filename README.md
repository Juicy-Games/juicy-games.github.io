# Juicy Games

This repository hosts `juicy-games.github.io`, a collection of playable experiments in game feel. Juicy Classics brings together seven browser games and lets you try different feedback effects and charge-and-release mechanics in the Juice Lab. [Play Juicy Classics](https://juicy-games.github.io/experiments/juicy-classics/)

This is a companion repository to Prajwal DSouza’s public **Juicy Game Design** repository, which contains the design guide and its own collection of classic game demos. [Juicy Game Design](https://github.com/prajwalsouza/juicy-game-design)
